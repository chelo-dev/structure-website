# Identidad de marca — Kharma Solutions / Angel Paredes

## 1. Decisión estratégica

La marca **Kharma Solutions** debe dejar de comunicarse como una agencia o estudio con un equipo y pasar a presentarse como una **marca comercial dirigida por Angel Paredes Torres**, desarrollador web independiente.

Modelo recomendado:

- **Marca comercial:** Kharma Solutions
- **Persona:** Angel Paredes Torres
- **Cargo:** Desarrollador Web
- **Especialidad:** Desarrollo Web & Sistemas a Medida

La relación recomendada es:

> Kharma Solutions  
> Desarrollo Web & Sistemas a Medida  
> por Angel Paredes

El objetivo es combinar la credibilidad de una marca con la cercanía y transparencia de trabajar directamente con el desarrollador.

---

## 2. Posicionamiento

### Posicionamiento principal

**Kharma Solutions — Desarrollo Web & Sistemas a Medida**

Propuesta:

> Soy Angel Paredes, desarrollador web independiente. Creo sitios web, tiendas en línea y sistemas administrativos personalizados para negocios y emprendedores.

Mensaje complementario:

> Desarrollo soluciones digitales pensadas para las necesidades reales de cada negocio.

### Diferencial

El principal diferencial no debe ser competir únicamente por precio, sino comunicar:

- Atención directa con el desarrollador.
- Desarrollo personalizado.
- Capacidad para desarrollar software real, no solamente sitios web.
- Comunicación directa durante el proyecto.
- Soluciones adaptadas a procesos reales de negocio.
- Posibilidad de mantenimiento, cambios y nuevas funcionalidades.

---

## 3. Personalidad de marca

La identidad debe transmitir cuatro conceptos:

1. **Personal**
   - El cliente sabe quién está detrás del proyecto.
   - Comunicación directa con Angel.

2. **Profesional**
   - Existe metodología.
   - El proyecto tiene etapas y alcance definido.

3. **Técnica**
   - Capacidad para desarrollar sitios, tiendas, sistemas, APIs e integraciones.

4. **Cercana**
   - No aparentar una corporación distante.
   - Lenguaje claro y humano.

Evitar mensajes como:

- "Somos líderes..."
- "La mejor agencia..."
- "Equipo multidisciplinario..."
- "Expertos altamente capacitados..."
- "Soluciones innovadoras..." como frase genérica.

Preferir:

- "Soy Angel..."
- "Desarrollo..."
- "Trabajo directamente contigo..."
- "Analizo tu proyecto..."
- "Creo una solución adaptada..."

---

## 4. Identidad verbal

### Voz

Profesional, clara, técnica cuando sea necesario y cercana.

### Persona gramatical

Usar principalmente primera persona singular cuando se hable de la experiencia y del desarrollo:

- "Soy Angel."
- "Desarrollo..."
- "Trabajo contigo..."
- "Analizo..."
- "Creo..."

Usar el nombre de la marca cuando se hable de la propuesta comercial:

- "En Kharma Solutions..."
- "Kharma Solutions ofrece..."

Evitar el uso excesivo de:

- "Somos"
- "Nuestro equipo"
- "Nuestros desarrolladores"
- "Nosotros"

cuando implique la existencia de un equipo que no existe.

## 7. Estadísticas y elementos de confianza

No utilizar estadísticas que no puedan demostrarse.

Evitar actualmente:

- 50+ proyectos entregados.
- 100% clientes satisfechos.
- 5 estrellas de calificación.

Además, corregir inconsistencias como mostrar 50+ proyectos en una sección y 40+ en otra.

Mientras se construye experiencia comercial, utilizar atributos verificables:

### Experiencia

Años reales de experiencia desarrollando software.

### Desarrollo personalizado

Sitios y sistemas adaptados a cada proyecto.

### Atención directa

Comunicación directamente con Angel durante el proyecto.

### Código propio

Desarrollo sin depender de plantillas genéricas cuando el proyecto requiere software personalizado.

Cuando existan métricas reales, sustituirlas progresivamente:

- 10+ proyectos desarrollados.
- 25+ proyectos desarrollados.
- etc.
